## Introduction / 简介

kkFileView is a document online preview solution built with Spring Boot, providing support for a wide range of document formats.

kkFileView 是一个文档在线预览解决方案，使用流行的 Spring Boot 搭建，易上手和部署。

### Supported Formats / 支持的格式

- Office documents: doc, docx, xls, xlsx, ppt, pptx, csv, etc.
- PDF, OFd, rtf documents
- CAD files: dwg, dxf, dwf, etc.
- 3D models: obj, stl, fbx, dae, etc.
- Images: jpg, png, gif, bmp, svg, tif, etc.
- Audio/Video: mp3, mp4, avi, mov, etc.
- Compressed files: zip, rar, 7z, tar, etc.
- And many more...
